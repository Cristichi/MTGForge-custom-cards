# Cristichi's MTG Forge custom cards
I'm using this repository to save my work on custom cards. Feel free to check, download, fork and modify for your own, or anything.

I also have here a few tools I developed to easily share cards for Windows users (.bat file), including the cards, the images, and any decks.

## Interested in testing the cards?
Check out the Releases page for the latest version of each Edition. If you see one edition from the repository is not there, it's because it's not finished yet (or discontinued).

Feel free to open issues for balance or wording or clarity on the cards you test.
